# SO-101 近期实验简报

记录时间：2026-11-14 22:40（北京时间）。任务是抓取黄色方块并放入网篮；机械臂使用双相机，`wrist_roll` 保持被动。

## 实验与结果

| 实验 | 结果与边界 |
| --- | --- |
| 旧 67 段数据的 SmolVLA | 曾训练并实机测试；部分试验出现提前闭夹、空夹和动作跟随延迟。现场布置与示教不同可能有影响，但尚无法确定单一原因。 |
| 新采集 22 段数据的 SmolVLA | 使用全部 22 段训练至 10,000 步；用户报告曾抓取成功，也有位置偏差、夹持或放置失败的尝试。没有独立验证集和系统成功率统计。 |
| 旧 67 段加新 22 段混合训练 | 训练中断后从检查点继续，得到 10,000 步模型。用户实机反馈不如新 22 段模型；测试条件未严格控制，不能据此认定旧数据造成污染。 |
| MolmoAct2 NF4 原模型 | 离线检查发现，现场画面下动作幅度偏小，且原执行程序只消费动作块首帧；视觉输入、坐标转换和动作时序都值得关注。旧版模型与本机坐标间需要双向肩肘转换。 |
| 官方 SO-101 权重与 NF4 | 单组相同输入、随机种子的离线对照中，30 帧各关节最大差约 0.5–2°，夹爪最大差约 0.28 个百分点。两者都输出小幅动作；单组结果不能推断实机成功率或泛化能力。 |
| new22 控制参数 | 用户测试五个主动电机 D=0、`SpeedTicks=6` 后反馈最后松开阶段出错；随后将运行入口默认 `SpeedTicks` 改为 3。该参数限制身体关节目标速度，不直接改变夹爪开合速度；两档效果尚无严格对照。 |

## 进行中的 MolmoAct2 NF4 微调

- 使用已校验的第三方 NF4 SO-101 基座和全部新 22 段、14,176 帧。数据输入与动作目标都转换为模型关节坐标，双相机顺序为外部相机、腕部相机。
- 冻结视觉语言基座；将动作专家中的 36 个 NF4 层解量化后，与其余动作专家参数一起训练。被动腕关节动作维度在损失中遮罩。批大小 1，目标 2,000 步。
- 单步前向、反向、优化器更新及动作专家权重保存回读已通过；优化器状态文件可读取。正式训练于 22:24 左右启动，22:39 左右超过 900 步，500 步检查点已保存。进度以实际日志为准。
- 每 500 步保存动作专家、优化器状态及预处理信息；该检查点依赖原 NF4 基座，尚未完成部署接口及实机验证。中断后的完整续训流程尚未验证。

## 结论与下一步

新 22 段模型已有一次用户报告的抓取成功，但当前尚不能比较 SmolVLA 与 MolmoAct2 的泛化能力，也不能仅凭训练损失判定实机效果。训练完成后，先接入 NF4 基座并核对坐标、归一化、双相机和完整动作块，再在一致场景下对比抓取与放置表现。
