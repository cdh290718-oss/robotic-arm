# 10k BF16 完整抓取尝试与受限推理

> 2026-11-11 新增 `-FixedWrist` 选项。它针对任务中不主动旋转的 `wrist_roll`；使用前请先读 [固定腕部模式说明](FIXED_WRIST_zh.md)。以下未带 `-FixedWrist` 的旧命令仍采用六电机位置写入，不能当作固定腕部模式使用。

可行性：双 RGB、六维关节状态、10k SmolVLA BF16 的本机预测已经在此前只读测试中运行成功。本包接通同一预测链到受限执行器，属于新的待实机验证版本。肘关节跟随不足尚未解决；程序仍可能因保护停止。不能将“预测完成”或“执行10秒完成”当成完整抓取验证成功。

按用户后续明确要求，新增 `Grasp`：模型控制全部六个关节，包括夹爪开合，尝试抓取黄色方块并放入网篮。工作范围采用训练时保存的校准范围，最长60秒。原有 `Execute` 保留±8°、固定夹爪、10秒限制。不要把两种模式混为一谈。

Grasp 的扩大仅涉及任务必需的目标工作范围与夹爪动作，不提高 PID、扭矩或电流上限。身体关节每30Hz周期目标最多1刻度（约2.64°/秒），跟踪偏差仍限制4°；夹爪目标速度最多5个归一化百分点/秒，实际量化后可能更慢，跟踪偏差超过5个百分点就停止。这些约束可能使抓取超过时限或提前停止，不能保证动作完成。校准范围不等于笛卡尔避障规划，本包没有识别自碰撞或桌面碰撞的规划器。

## 使用

无需安装依赖或下载模型，使用 `G:\LeRobot\.venv`、现有离线10k权重、配置和训练校准。机械臂通电并连接COM5，两路镜头无遮挡；关闭校准、遥操作、只读网页运行和其他控制程序。不要点校准页面来查看位置。

第一步只读完整抓取预测（模型预测和限幅日志，电机不写入）：

```powershell
cd G:\LeRobot\policy_trial_kit
powershell -NoProfile -ExecutionPolicy Bypass -File .\Run-Policy.ps1 -Mode GraspPredict -Seconds 10
```

GraspPredict 不发送电机写入。模型加载和5次预热另计；实际运行时间从新预测准备完成后起算。它保存双相机截图、完整50×6动作预测、限幅目标与关节状态。模型实际执行的输入会随着运动变化，因此只读预测不能替代实机验证。

GraspPredict 完成，起始姿态稳定、扭矩关闭后，可尝试完整抓取：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Run-Policy.ps1 -Mode Grasp -Seconds 60
```

本包要求 P=16、I=0、D=32、Lock=1，夹爪 Max_Torque_Limit不超过500，校准与训练档案一致。不会修改 PID、扭矩上限或校准。跟踪误差、输入过旧、推理故障、位置越界等会停止。相机近乎全黑也会拒绝。夹爪接触物体后若实际位置与目标差距过大，也会触发保护，不能为完成夹持就自动增加力量。

`STATUS: completed` 仅表示持续运行到时间上限。程序没有自动判定物体已成功抓起/放入网篮，报告中的 `grasp_success_verified` 始终为 false，实际成功需要人工观察确认。

如果仍希望先试固定夹爪的短程动作，可以用 `-Mode Predict -Seconds 10`、再 `-Mode Execute -Seconds 10`。完整抓取使用上面的 GraspPredict/Grasp 命令。

位置写入触发扭矩开启已在本设备被观测到。本包将当前姿态的首次目标写入作为可能激活扭矩的动作；两次读取确认已开启且姿态稳定，才开始模型动作。没有额外发送 Torque_Enable=1。若设备表现不同则中止并尝试关闭扭矩，不能以此推断该现象已获得厂家解释。

保持终端焦点。Ctrl+C / Esc / 空格停止。**启动成功后停止会保持当前位置、扭矩开启；启动未完成时失败则尝试关闭扭矩。** 请安排支撑以应对启动失败后的松力。运行结束需松力时，先承托机械臂，再执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Run-Policy.ps1 -Mode Release
```

如日志显示 hold_not_confirmed 或 cleanup_not_confirmed，不应认为软件已保证停止/保持/松力成功，需现场处理通信与设备状态。

## 回传

将每次 `SEND BACK: ..._return.zip` 发回，包括失败的包。文件位于本目录 `results`。包中包含执行摘要、失败位置与上一条目标、控制日志、模型预测与计时、相机截图。另请描述是否抓起、放下，或在哪一步停止。

若起始校准或范围检查失败，原样回传，不重新校准来绕过。此前 wrist_roll 曾为2031而原保存范围为2042～2051，这种情况下会在动作前退出。

## 离线自测

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Run-Policy.ps1 -Mode SelfTest
```

自测使用假总线、假相机与假预测，不连接机械臂。30项测试覆盖启动与异常清理、写入许可、动作限幅、夹爪缓慢开合与跟踪保护、只读无写入、模型进程/控制循环模拟、中文路径截图保存，以及起始姿态越界时记录具体关节和范围。

2026-11-10 更新：起始位置现在会在限位检查前写入回传；错误会显示关节名、当前读数及允许范围。未修改限位或控制行为。

另外，真实10k BF16权重已用离线图像和模拟机械臂完成2秒完整抓取模式联调：57个控制周期，正常结束，硬件写入包为0。这验证了真实模型到新控制器的数据链路，不代表真实机械臂动态、夹持或抓取成功已验证。
