# 固定腕部旋转模式

本模式适用于 `wrist_roll` 不需要主动旋转的情况；用户已确认该关节没有损坏，平时不人为拨动不会自行转动。保留 SmolVLA 六维输入/输出；模型接收腕部实际测量值，不替换成训练均值。忽略模型的腕部旋转动作，不对电机 ID 5 发送 Goal_Position，也不发送开启扭矩写入。紧急关闭扭矩时允许向包括 ID 5 在内的全部电机发送 Torque_Enable=0。

已在 Windows 通过真实相机、真实关节读取、10k BF16 模型完成10秒只读预测：296个观测周期、40组50×6有限值动作，电机写入0，结束六电机扭矩均为0。42项模拟测试通过，覆盖串口目标包不含ID 5、意外扭矩开启时释放、腕部漂移停止、分布外状态拦截、其余关节限位和只读零写入。**尚未实机验证向其他五个电机发送目标时，电机5是否在该固件上始终保持扭矩关闭。**

## 重复只读预测

先关闭其他控制/校准程序，确认从臂供电及两路相机连接。PowerShell：

```powershell
cd G:\LeRobot\policy_fixed_wrist_kit
powershell -NoProfile -ExecutionPolicy Bypass -File .\Run-Policy.ps1 -Mode GraspPredict -Seconds 10 -FixedWrist
```

固定腕部模式采用本包 `robot_config_fixed_wrist.json`：DSHOW，逻辑1/夹爪相机索引0、逻辑3/外部相机索引2。2026-11-11通过画面核对；USB重新连接或设备顺序变化后必须重新核对，设备的英文名称并不足以证明其视角。输出包内 `camera_before.jpg` 和 `camera_last_observation.jpg` 可用于确认画面，不应自动上传未经确认的个人画面。

每次显示 `SEND BACK: ..._return.zip`；包内包括真实状态、完整动作预测、相机画面、输入标准分数和串口写入计数。可回传失败包。只读模式不会主动更改当前扭矩；如果开始时扭矩已开启，仍应以报告的前后回读为准。

## 运行边界

- 用户当前要求先验证只读预测。实机 `Grasp` 不应因只读通过就被认为已验证；肘关节跟随不足和本机目标写入后扭矩变化仍待实机研究。
- 当首次位置写入触发意外扭矩时，所有可能已上扭矩的电机都将尝试释放；若读取或释放失败，报告明确显示未确认。启动成功后的正常停止尝试保持其他五个电机，同时要求ID 5扭矩关闭。软件无法保证串口/电源故障时的状态。
- 在固定腕部模式，每次目标写入前后读取ID 5扭矩；若发现意外开启或状态读取失败，停止并尝试关闭全部扭矩。运行时腕部相对起点漂移超过11刻度（约0.97°）也会停止。
- 当前实际腕部位置1994，对应约−4.62°；最近真实只读预测中该维相对训练均值约−23.5个标准差。有限值预测不能证明这种分布外状态下的行为可靠。固定腕部实机模式在该维超过5个训练标准差或数据不可用时，会在首次位置写入之前拒绝启动。5是保守启发式阈值，不是已验证的安全边界。
- 本模式仅对不发送目标的wrist_roll不采用旧的2042～2051范围检查，改为以真实起点为参考监测漂移；其余各关节继续按已有校准、速度和跟踪误差限制。没有重新校准，也不更改PID、扭矩上限或夹爪保护。
- 腕部被动不代表机械锁止，若在运动、重力作用或接触下仍发生变化，只读观察和每周期检查不能保证瞬时稳定。

## 离线自测

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Run-Policy.ps1 -Mode SelfTest
```

不连接串口；使用假总线、假相机和假模型。`probe_cameras_readonly.py` 可在本机检查摄像头并保存本地图像，可能包含个人画面，不应直接公开。
