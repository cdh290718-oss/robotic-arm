# 腕部位置只读显示

此工具只读取腕部和六电机扭矩，不发位置目标、扭矩开启/关闭、校准或参数写入。运行时不要同时使用其他占用 COM5 的程序。

先承托好机械臂。工具确认六电机扭矩均为0后，若腕部旋转关节能轻松转动，可轻微手动调整，观察读数回到 **2042～2051**（靠近2046即可），不要强行掰动。范围来自现有训练校准，不是重新校准。位置达到后无需持续主动旋转该关节。

```powershell
cd G:\LeRobot\wrist_position_watch
powershell -NoProfile -ExecutionPolicy Bypass -File .\Watch-Wrist.ps1
```

每0.5秒显示原始读数、训练范围和相对训练均值的标准分数，默认120秒。Ctrl+C、Esc或Q停止；若发现任何电机扭矩不是0或通信异常则立即退出。它不会关闭扭矩，也不能保证串口故障时状态。结果ZIP保存在本工具 `results`；不含相机画面。

扭矩关闭是可移动的前提，但不能排除机械卡阻或本次位置/安装姿态与训练时不同；若感觉阻力明显，停止手动调整。之后先使用固定腕部 `GraspPredict` 只读预测复核，而不是直接执行抓取。
