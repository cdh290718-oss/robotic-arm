# 双相机实时预览

程序只打开摄像头，不连接机械臂、不发送电机指令、不改变扭矩或校准，也不录制或上传画面。关闭占用相机的控制或视频软件后，可直接双击 `Run-Cameras.cmd`，或在 PowerShell 中运行：

```powershell
cd 'D:\桌面\萌芽杯\camera_alignment_preview'
powershell -NoProfile -ExecutionPolicy Bypass -File .\Run-Cameras.ps1
```

窗口上排是保存的示教参考（验证集第 56 段约 10% 处，不一定是第一帧），下排是实时画面。左侧为外部相机，右侧为腕部相机；按 R 隐藏或显示参考图，按 Q 或 Esc 退出。没有参考文件时仍可看实时画面。

默认沿用上次核对过的 Windows DSHOW 编号：外部 2、腕部 0。USB 重新插拔后编号可能变化；若画面交换或黑屏，确认相机实际视角，并按设备实际编号调整：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Run-Cameras.ps1 -External 0 -Wrist 2
```

预览会占用这两路相机；运行模型前按 Q 退出。参考画面帮助对齐，但无法从图像直接恢复精确的物理位置。
