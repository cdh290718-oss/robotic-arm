# 肘关节起动误差诊断

这是一项实机动作测试，不运行模型。P 只读，必须为 16；不会更改校准或 PID。每个方向 1 刻度/100 ms，实测沿该方向移动至少 3 刻度，或目标与实测误差达到 40 刻度，就停止增加该方向目标。40 刻度内无可见起动会标为 `not_observed_within_40_ticks`。两个方向之间对齐当前位置并检查稳定；4°跟踪检查仍生效。腕部 ID 5 不接收目标或上扭矩写入；结束会对六个电机发关闭扭矩命令。

1. 结束所有机械臂控制和校准程序。确认机械臂断电或扭矩关闭，在托住机械臂的情况下，将肘关节轻放在行程中部，不要强扳或保存校准。接通电源和 USB，确认 COM5 未被占用。整个测试期间托住机械臂，并避免阻碍肘关节运动：启动或结束时扭矩状态可能变化，结束会关闭扭矩。
2. 在 PowerShell 中运行：

```powershell
cd 'D:\桌面\萌芽杯\elbow_start_threshold'
& 'G:\LeRobot\.venv\Scripts\python.exe' .\threshold.py --run
```

3. 保持终端有焦点。需要停止时按 Esc、空格或 Ctrl+C；程序会尝试关闭扭矩，通信故障时不能保证关闭成功。不要仅依赖软件停止保护。
4. 等待 `SEND BACK:`，将其后的 ZIP 发回。失败时也请发送；若显示 `RELEASE CONFIRMED: False`，不要假定已经关闭扭矩。

`summary.json` 保留逐周期原始位置、目标、负载和电流、时间、停止原因以及写入帧。方向是编码器原始值的正负，并非物理上的上下。起动误差是观察到 3 刻度位移时的目标减实测值，受采样周期、静摩擦和间隙影响，不能换算为物理扭矩。结果仅适用于当时姿态和负载。
