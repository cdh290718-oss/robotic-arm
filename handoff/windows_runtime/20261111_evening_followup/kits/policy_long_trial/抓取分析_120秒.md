## 限幅与跟随

剔除 19 个无预测周期，按校准范围将模型原始目标转为原始刻度，计算 `abs(原始目标 - 已限幅命令)` 和 `abs(已限幅命令 - 实测)`。单位为角度；夹爪为归一化百分点。

| 关节 | 原始目标与命令差：中位数 / 95% | 命令与实测差：中位数 / 95% / 最大 |
|---|---|---|
| shoulder_pan | 0.53° / 3.34° | 0.35° / 0.62° / 0.97° |
| shoulder_lift | 6.33° / 41.93° | 0.62° / 2.37° / 2.81° |
| elbow_flex | 3.78° / 23.82° | 1.76° / 2.99° / 3.87° |
| wrist_flex | 1.32° / 6.24° | 0.44° / 0.88° / 1.32° |
| gripper | 0.62 / 8.16 百分点 | 0.41 / 0.69 / 0.83 百分点 |

仅 shoulder_lift 在 6 个有效周期的模型目标越过保存范围，其他受控关节的目标在范围内；大量模型目标和命令的差距主要反映逐周期速度限制产生的滞后，而非全部是工作范围裁剪。统计 `clipped=True` 只表示最终目标不同于模型目标，不能单凭计数证明截断幅度或原因；被动 wrist_roll 永远忽略模型目标，不能用于评估其他电机。

20.01 秒时，模型对 shoulder_lift 的目标约 -22.0°，实测约 -65.2°，说明模型意图和当时状态差距大；同一时间肘关节目标约 33.1°、实测约 50.4°。这个差距不是电机跟踪已发送命令的差距，不能误判为舵机物理故障。模型目标本身随观测持续变化，两者相差也不能证明去掉限制就会成功。

## 夹爪与模型时间

模型夹爪预测从第 20 秒后的 24%～28% 一度降低。71.09 秒时预测约 4.54%，但实测约 19.64%，已发命令约 19.16%。20 秒后，模型预测小于 10% 的最长连续区间约 0.51 秒；夹爪命令速度上限是 5 个百分点/秒，仅按该上限从约 20% 到 5% 需要约 3 秒，而预测可能在此之前改变。限速导致模型预测闭合与实际执行存在时序错配是有数据支持的可能性；但只有首末画面，无法确认该时刻方块与夹爪的接触关系或这一原因是否决定了失败。

模型动作块按每块 50 帧、30Hz 编码，当前逻辑依据从观测时刻算起的时间选择 `int(age*30)`。226 个被使用的动作块首次被执行时，索引中位数为 18、95% 为 24（即首次使用常跳过块的前 18 帧）；块输出时输入年龄中位数 609ms、95% 799ms。这是实现策略，并非直接证明 bug；这样做避免执行过期动作，但加上限速可能产生时间错配。每个控制周期的动作块观测年龄中位数约 912ms、95% 1349ms。

## 现场和建议

最近现场画面比上次更接近验证样本，但不能从画面判定三维物理位置、深度或相机外参已完全恢复。不能用本次结果确认 D 参数导致失败；前后试验姿态、场景均不同。

先做不驱动机械臂的回放，比较不同时序策略下的目标偏差、延迟和夹爪闭合持续时间，并保留原始日志。原有 4° 跟踪、固定腕部、校准边界和异常清理不得因为离线结果自动放宽。若要改变速度，属于改变实机运动行为，应在结果可审阅后经用户明确选择，再做小幅受控验证。模型能输出有限值和运行到时限，均不等于成功抓取。
