# LeLab 10k BF16 只读预测入口

入口：http://localhost:8000/so101-readonly

LeLab 首页右下方新增「10k 只读预测」链接。刷新已有页面即可看到。使用原 G:\LeRobot 环境、原 10k 模型和原校准，不需要安装依赖或重新训练。

## 使用

1. 两路镜头无遮挡，停止其他相机/机械臂控制程序。
2. 「检查相机与状态」读取双相机和关节状态，不加载模型。
3. 「开始只读预测」加载完整 010000 checkpoint，使用明确 BF16 和原 processor，预热后生成 50×6 动作预测。
4. 「停止」请求工作进程收尾；页面显示已停止后，可下载本次回传 ZIP。关闭浏览器不会替代停止操作，但每轮最多采集/预测60秒，另有进程超时监督。

页面显示外部/腕部图像、关节实测、模型首步预测、差值、完整推理耗时、预测计数及结束扭矩回读。末次预测保留到下一组完整结果生成，不把正在计算的新输入冒充已完成预测。

这里不发送机械臂动作，不启用/关闭扭矩，不写 PID 或校准。底层复用已验证的 ReadOnlyPacketGuard，仅允许 PING、READ、SYNC_READ。启动若读到扭矩开启则拒绝继续，且不会自行释放。黑画面会阻止模型启动或停止后续预测。

## 与原 LeLab 的关系

- 已登记的模型名仍是「0918 SmolVLA 10k（待适配，勿启动实机）」。登记项不是实机验收结果。
- 该模型的旧 /start-inference 路径被拦截并指向只读入口。
- 新入口运行期间，与 LeLab 的遥操作、录制、校准和实机推理启动互斥，并阻止并行相机扫描。
- 沿用双 RGB 640×480、30FPS、MJPG；逻辑3→camera1，逻辑1→camera2；没有伪造第三路。
- 不改原 checkpoint 的配置、模型权重、processor、校准文件或旧 execution_kit。
- 现有录制恢复脚本保留；未重新构建覆盖 frontend/dist。
